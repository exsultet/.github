# exsultet/.github

Arquivos padrão da organização Exsultet no GitHub.

- `profile/README.md` — página pública da organização.
- `CONTRIBUTING.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md` — valem para todos os repositórios que não tiverem os seus próprios.
- `ISSUE_TEMPLATE/` e `pull_request_template.md` — templates padrão de issue e PR.
